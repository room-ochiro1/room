# room

Креатив маркетингийн агентлагийн landing page — видео эдит, зураг авалт, landing page хөгжүүлэлт, реклам ажиллуулах.

Next.js 16 · React 19 · Tailwind CSS 4

## Ажиллуулах

```bash
npm install
npm run dev
```

http://localhost:3000 хаягаар нээнэ.

## Агуулга засах

- Текст, үнэ, төсөл, FAQ: `src/lib/data.ts`
- Видео: `public/videos/` (poster зураг: `src/assets/posters/`)
- Өнгө, фонт: `src/app/globals.css`
